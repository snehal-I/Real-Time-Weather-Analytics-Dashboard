# Real-Time-Weather-Analytics-Dashboard
# Weather Analytics Dashboard 🌤️

Interactive real-time weather dashboard built with **Power BI** for environmental monitoring and air quality analysis.

# Features

- **Real-Time Data Integration** - Live weather API data with automatic refresh
- **8+ Interactive Visualizations** - AQI gauges, temperature trends, sunrise/sunset, location comparison
- **Air Quality Monitoring** - Track PM10, NO2, SO2, CO, PM2.5 levels
- **Dynamic Filtering** - Compare metrics across Ajmer, Mumbai, and Nasik
- **Smart Calculations** - DAX measures for temperature variability, AQI assessment, "feels like" temperature
- **Color-Coded Insights** - Visual indicators for quick decision-making

# Tech Stack

| Tool | Purpose |
|------|---------|
| **Power BI** | Interactive dashboard & visualizations |
| **Power Query** | Data cleaning & ETL |
| **DAX** | Complex calculations & measures |
| **Weather APIs** | Real-time meteorological data |

# Data Refresh

- **Desktop:** Ctrl + R
- **Service:** Auto-refresh every 30 minutes
- **Manual:** Refresh button on dashboard
